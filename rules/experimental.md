# Experimental lane rules

The experimental section helps the user discover genres they have not tried.

1. Pick genres, countries or eras that are absent or rare in the user's history.
2. Choose well-rated, accessible entry points (not obscure or very long titles).
3. Explain the bridge: connect the pick to something the user already likes.
4. Limit to 5 picks per refresh.
5. If the user watches and rates an experimental pick 7+, promote that genre into the main feed rules for the user's taste profile. If they drop it, note it and avoid that genre for a while.
